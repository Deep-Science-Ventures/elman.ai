# /thesis/ and /demo/ are linked from the homepage and open to any visitor.
# /thesis/ is indexed and in the sitemap. /demo/ still carries <meta
# robots="noindex">, which is what keeps it out of search results. Do NOT
# re-add a Disallow for either: a crawler blocked by robots.txt never fetches
# the page, so it never sees the noindex, and Google can still list a blocked
# URL as a bare result. Crawl-then-obey is the config that actually works. To
# index /demo/, delete the noindex meta from it and add the URL to sitemap.xml.
#
# /mission/ is the old home of /thesis/ and is now a meta-refresh redirect
# stub. It must stay crawlable for Google to follow the redirect and move the
# old URL's ranking across.

# The blocks below are redundant against the wildcard above and exist as a
# standing decision, not a change in behaviour: Elman wants to be retrievable
# and citable by AI assistants. Three kinds of agent are named, because they do
# different jobs and a future blanket Disallow should have to argue with each
# one separately:
#   - search indexers (OAI-SearchBot, Claude-SearchBot, PerplexityBot) decide
#     whether we can be cited in an AI answer at all. These are the ones that
#     matter for /careers/ and for anyone asking an assistant about Elman.
#   - user-triggered fetchers (ChatGPT-User, Claude-User, Perplexity-User) pull
#     a page live when a person pastes or asks about a URL.
#   - training crawlers (GPTBot, ClaudeBot, Google-Extended, CCBot) feed model
#     training. Allowing these is the arguable one. Leave them allowed while we
#     are trying to be found; revisit if we ever publish something we would
#     rather not have memorised.
